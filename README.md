# Tarot
这是一个沉浸式塔罗牌占卜网页，融合了神秘美学与现代交互技术。项目采用纯前端实现（HTML+CSS+JavaScript），拥有完整的78张塔罗牌数据（22张大阿尔卡纳+56张小阿尔卡纳）。视觉上以暗黑神秘为基调，背景是实时流动的星河特效—包含银河带星群、漂浮星云、随机流星，营造深邃的宇宙氛围。 交互流程支持单张牌和三张牌（过去-现在-未来）两种牌阵，用户可输入想咨询的问题后进入抽牌环节。抽牌页采用3D轮播卡牌展示，支持鼠标/触摸左右滑动切换卡牌、向上滑动抽取。每次抽牌伴随粒子爆炸特效，抽完后卡片弹出并触发魔法星光飘落，卡牌自带呼吸光晕。解读部分集成 DeepSeek AI API，生成流畅的散文式中文解读，为用户提供温暖而有洞察力的占卜体验。
